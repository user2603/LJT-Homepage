## Running locally

This site is a standard Jekyll site. To preview it locally:

1. Install ruby-dev, bundler, and nodejs.
2. Run `bundle install` to install the Ruby dependencies.
3. Run `jekyll serve -l -H localhost` and open `localhost:4000`.
